# Telegram Calendar Reminder Bot (@BirdEntertainmentSBS24bot)

A complete, production-ready Telegram Calendar Reminder Bot built with Python, `python-telegram-bot`, `SQLite`, and `APScheduler`.

## Features
- ⏰ Automatic reminders with timezone support.
- 🗓️ Interactive inline keyboard calendar.
- 🔄 Recurring reminders (Daily, Weekly, Monthly, Yearly).
- 💾 SQLite persistent database.
- 🚀 Ready for deployment on Render worker instances.
